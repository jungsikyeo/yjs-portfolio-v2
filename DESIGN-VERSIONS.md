# Design history

- **v1 — First glass**: Git tag `design-v1` / commit `e68c7bc`. Theme switch, GitHub portrait, three topology selection treatments.
- **v2 — Prismatic glass**: Git tag `design-v2` / commit `823e949`. Colored backdrop, translucent panels, floating navigation, blurred modal backdrop.
- **v3 — Soft neumorphism**: Based on a neumorphic reference slide. Warm gray surfaces, soft raised and recessed controls, muted sage/ochre accents. Default light theme, separate remembered v3 theme choice; dark theme retained. Selected nodes use an inset pressed surface. Detail backdrop blur retained.

Tags preserve complete source states. Changes between versions can be compared without checking out or overwriting the current workspace.
